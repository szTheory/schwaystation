# Roadmap: schwaystation

## Overview

The v1.0 GSD milestone is complete. schwaystation ships a deterministic PlayStation C library, headless runner and
libretro core, with tested CPU/GTE, GPU, SPU, CD-ROM and owned disc boot paths. Every phase release is merged and
the latest automatic package release is v0.6.0.
