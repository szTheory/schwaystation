## Cross-phase integration

The read-only integration checker traced the full consumer paths in source and found zero blockers. Shared disc providers validate the common disc descriptor before runner and libretro use it. Failures do not partially replace an active disc. Card sockets connect the core serial protocol to runner files and libretro save RAM/extra slots. Profile selection reaches timing and serialized state. Libretro input is latched at the frame boundary and reaches the serial devices. Patch overlays reach runner sector reads; cheat parsing reaches checked core writes and state/hash handling. Compatibility evidence reaches the guarded metadata claim.

| Flow | Requirements | Path | Status |
|---|---|---|---|
| Media providers | MEDIA-01, MEDIA-02, CHD-01, PBP-01, ECM-01, CCD-01 | Provider readers → common disc descriptor → runner and libretro | WIRED |
| Protected-disc Q data | CRYPT-01 | SBI parser → bad-Q callback → CD sector handling → GetlocP | WIRED |
| Card lifecycle | SAVE-01–05, SIO-01 | Content/serial identity → card sockets → runner persistence and libretro SAVE_RAM/extra slots | WIRED |
| Machine profile and boot | PROFILE-01, PROFILE-02, BOOT-01 | Runner/libretro options → validated core profile → timing/state and eligible boot path | WIRED |
| Special controllers | SIO-02–05, GUN-01, GUN-02 | Host input → frame latch → serial protocol or gun beam sampling | WIRED |
| ROM-hacker support | PATCH-01, CHEAT-01 | Runner patch parser → immutable disc overlay; runner/libretro cheats → checked writes and hashes/state | WIRED |
| Compatibility evidence | COMPAT-01–03 | Pinned DAT and feature ledger → required capability evaluator → generated metadata claim | WIRED |

Self-contained requirements with no cross-phase consumer are TUNE-01–06 and MDEC-01; the pinned DAT inventory part of COMPAT-01 is also a self-contained evidence source. These were checked directly against their phase verification and integration controls. One documented host policy distinction remains intentional: runner card files can use serial or content-digest identity, while libretro extra-slot paths use the content basename ([docs/saves.md](../../docs/saves.md)); no requirement requires the same filename policy across both host APIs.

No unmeasured change or dropped check is recommended.

Act and local evidence already cover the applicable workflow routing and selectors in Phase 16's local evidence. No new `act` run adds useful coverage for this planning-only closeout. The local doc and budget preflights passed during the Phase 16 verification; the full required hosted source and release gates passed on the released head.
