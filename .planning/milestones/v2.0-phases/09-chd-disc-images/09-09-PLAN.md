## Evidence-backed scope adjustment

The metadata guard belongs in `libretro/CMakeLists.txt`: it configures the `.info` file and can inspect `schwaystation_disc_image`'s actual `LINK_LIBRARIES`. The root `CMakeLists.txt` does not generate that file. `cmake/packaging.cmake` already installs root `LICENSE` and `THIRD-PARTY-NOTICES.md` into each `library`, `runner`, and `libretro` component. `tests/cmake/archive_contents.cmake` already checks the exact ZIP member sets and byte hashes of both notice files; Plan 13 owns the ON/OFF package runs, so both files stay unchanged.

The generic tracked-source SPDX scanner remains in todo 005, bound to the first later phase that adds a tracked SPDX-bearing source. Phase 9 adds no such tracked source: the pinned CHD closure is fetched into the build tree and its licenses were audited at Plan 09-02. This plan carries those exact notices, derives the `.info` claim from the actual linked target, and retains the existing manifest/path and archive-member/hash gates. `cmake/packaging.cmake` already installs both root notices into all three components; Plan 13 owns the enabled/disabled archive executions. The line budget does not allow a safe generic scanner here without cutting required checks.
