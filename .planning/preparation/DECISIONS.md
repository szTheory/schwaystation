# Decisions already made

Each row is settled for v1.0 unless a phase finds new evidence; a change keeps the ID, gives the date and links the
evidence. IDs use a dot (`DEC.07`) so they never collide with GSD's `D-NN` phase decisions. "See" names the
preparation file and section (SYS = PSX-SYSTEM, GPU = PSX-GPU-AND-GTE, SCM = PSX-SPU-CDROM-AND-MDEC, PER =
PSX-PERIPHERALS-AND-SAVES, ECO = PSX-ECOSYSTEM-AND-USERS, PX = PSXDEV-EXTRACTS, CF = CONFORMANCE, ENG =
ENGINEERING, HI = HOSTS-AND-INTEGRATION, PV = PROVENANCE.md, AP = ASSET_POLICY.md). Markers (unverified),
(derived) and (tested) are carried over from the file cited.

## Time and bus
| ID | Decision | Because | See |
|---|---|---|---|
| DEC.09 | The tick is one CPU cycle at 33,868,800 Hz in a `uint64_t`; the GPU clock comes from an exact ratio accumulator (numerator 715909 NTSC or 709379 PAL over 451584); dot clocks divide the GPU clock by 10/8/7/5/4; the SPU steps every 768 ticks; a CD sector every 451,584 ticks at 1x; no floating point anywhere | The CPU, DMA, timers, SPU and CD are exact in sysclk and no small LCM with the GPU clock exists | SYS 1, C1 |
| DEC.10 | Line length 3413 (NTSC) / 3406 (PAL) GPU clocks with the accumulator; 263 / 314 lines per progressive frame; hosts are told the emulated rates 53693175/897619 (59.8173) and 53203425/1069484 (49.7468) progressive, the field rationals 1431818/23891 and 2128137/42575 interlaced (ARCH 1), so fps and samples per frame agree exactly; the nominal 59.826/49.761 stay documentary; nothing on by default changes speed | Implementation consensus; the measured refresh figures imply 3412.5 / 3405.02, which is an open question; reconciled 2026-10-19 (ARCH 13 row 2) | SYS 1, C2; HI 1; GPU 4.1; ECO 2 C.12 |
| DEC.11 | A frame runs from vblank to vblank (GPU vblank at Y2, release at Y1 as ares models it); input is latched at that boundary; `schway_run_frame` and `schway_run(budget, &stop)` return one stop reason from the single enum FRAME, BUDGET, AUDIO_FULL, HOOK (breakpoint, mailbox, tty line, exit port), FAULT, LID (ARCH 1, 13 row 10) and never sleep; no wall clock, no busy loop | Lowest input latency; bounded calls; handheld and browser hosts drive pacing | GPU 4.1, 7.A; HI 7; ENG 14; SCM 6 SYNC |
| DEC.12 | Bus decode on the physical address (mask 1FFFFFFFh after a segment switch); the delay-register formula charged for every port; RAM_SIZE bank mirrors and bus faults real; memory-control registers writable with the retail boot values as the profile default | Documented and relied on by games; an EXE that never runs the BIOS sees the same timing | SYS 3, C4 |
| DEC.13 | One DMA scheduler on the CPU tick runs whole slice blocks or linked-list nodes atomically, charges per-word costs (MDEC, GPU, OTC 1; SPU 4; CD 24 or 40), stalls the CPU by the documented rule, chops sync-0 transfers as alternating windows | Documented model that ares reproduces; per-word interleaving is the fallback | SYS 4, C5 |
| DEC.14 | Timers step from sysclk (and /8) and from GPU events (dots through the accumulator, hblank at display X2), with the 2-cycle write hold and the 1 or 2 cycle zero dwell | ps1-tests `timers` and ares agree | SYS 5, C6 |
| DEC.15 | I_STAT is edge-set; CAUSE bit 10 is the live AND of I_STAT and I_MASK, not latched; a new interrupt is taken after ares' two-instruction delay until a test moves it | psx-spx rule; the delay is ares' inference, so it is an open question | SYS 6, 10 |
| DEC.16 | Power-on image per SYS 9 (SR = 00400000h, PRID 2, DPCR 07654321h, timers 0 with bit 10 set, I_STAT and I_MASK 0, RAM zero by default with a `ram_fill` seeded option); `reset` re-applies the table but keeps RAM, VRAM and SPU RAM | Tests need fixed values; the console has only a power switch | SYS 9, C9 |
| DEC.17 | Regions keep their own crystal: a PAL title on an NTSC profile runs at 50.460/50.219 Hz and an NTSC title on a PAL profile at 59.393/59.280 Hz, as hardware does; the region comes from the disc (serial, licence string, EXE marker) with a user override, never from the video mode a game selects | Documented hardware behaviour; TASVideos requires the region to match | SYS 8; GPU 4.1; PER 5.2; ECO 3.3 |
| DEC.18 | Linked-list DMA is guarded at 1000h nodes, MADR wraps at FFFFFCh, a node above the RAM window raises the DMA error some games use to end a chain; a self-referencing list (ps1-tests `chain-looping`) terminates by the guard, never by a host timeout | Hostile command streams must not hang a frontend | SYS 4; CF 6 |
