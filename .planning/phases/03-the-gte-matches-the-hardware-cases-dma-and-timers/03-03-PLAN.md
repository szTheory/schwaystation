<objective>
Build the scheduler spine the GTE, DMA and timers share: an always-on block clock, the derived next deadline that
limits each block, the event runner, the freeze-until CPU stall, and the vertical-blank push at the frame end.

Purpose: D-23, D-24, D-10, D-20 and D-33. The devices behind it are stubs until wave 3, so this plan's tests drive
the spine directly (a stall set in the DMA state, a deadline set in the cache); the device plans add the end-to-end
tests. The cop2 dispatch and the interrupt hook fix D-37 also names for the spine are plan 03-06, the second half of
the spine, because both touch `src/cpu_exec.inc` and one plan would pass 30 minutes.
Output: `src/sched.c` filled, `cpu_run` and the block clock, `frame.c` vblank push, `tests/core/sched_tests.c`, a
section of `docs/hardware/cpu.md`.
</objective>
