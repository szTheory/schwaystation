<objective>
Wire the bus for the three devices: the DMA and timer ranges become owned, DMA gets a fault-free RAM word path, every
bus read and fetch reports itself to the DMA stall check (stores wait only at the fifth queued store, which plan
03-03 hooks), and I_STAT reads and writes keep the timers current.

Purpose: D-09, D-10 (the read and fetch side; the fifth-queued-store side is plan 03-03's edit to `src/cpu_exec.inc`,
which this plan never touches), D-14, D-18 and the D-26 stub replacements, done once here so the DMA and timers plans in wave 3
never touch `bus.c`, `irq.c`, `tests/core/bus_unbuilt.c` or the `unbuilt` fixture, and can run beside each other.
Output: edits to `src/bus.c`, `src/bus.h`, `src/irq.c`, the two stubs, the sweep, `bus.ram_word`, the `unbuilt`
fixture and its test, two docs pages.
</objective>
