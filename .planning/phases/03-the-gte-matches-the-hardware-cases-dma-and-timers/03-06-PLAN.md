<objective>
Finish the spine on the CPU side: COP2 instructions reach the GTE, the GTE busy stall applies to the right
instructions, and the interrupt entry executes a pending GTE command once more, reading the right word without side
effects.

Purpose: D-05, D-06 (with phase-2 review finding IN-01 fixed first: "first" means before the double-execute is built
on it. Today `schway__cop0_irq_entry_cop2` only classifies the word and executes nothing, so the wrong word cannot act
while Tasks 1 and 2 land; Task 3 makes the peek fix and its delay-slot test its first edit, before the hook executes
any command, and the tracer stays Task 1), D-26's COP2 stub replacements and GTE-01's
"cycle counts and busy stall in `tests/cpu/timing_tests.c`". It relies only on `gte.h`'s interface and the cycle
table from plan 03-01, so it runs beside the seed plan 03-26 (wave 3) with no shared file. The tests use registers whose read
equals the value written under every documented fix-up (data register 0, control register 0), so they stay true when
the seed adds the fix-ups.
Output: `cpu_cop2` and `cpu_irq_enter` changes, the hook in `cop0.c`, `tests/cpu/cop2_tests.c`, rewritten exception
and timing cases, two docs sections.
</objective>
